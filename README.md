# Task 1 — Titanic Survival Prediction

## Description

The Titanic Survival Prediction project focuses on predicting whether a passenger survived the Titanic disaster based on passenger-related information.

The internship task uses passenger attributes such as age, gender, ticket class, fare, cabin, and survival status.

## Key Steps

* Load the Titanic dataset.
* Perform Exploratory Data Analysis (EDA).
* Handle missing values.
* Perform data preprocessing.
* Convert categorical variables into numerical form.
* Select relevant features.
* Split the dataset into training and testing sets.
* Train a Machine Learning classification model.
* Make predictions on test data.
* Evaluate the model using suitable classification metrics.

## Machine Learning Concept

**Classification**

The objective is to classify passengers into two categories:

* Survived
* Did Not Survive

The three species are:

## Key Steps

* Explore the dataset.
* Analyze sepal and petal measurements.
* Prepare the features and target variable.
* Split the dataset into training and testing sets.
* Train a classification model.
* Predict the flower species.
* Evaluate model performance.

## Machine Learning Concept

**Multi-Class Classification**

The model predicts one of three possible flower species.

# Task 4 — Credit Card Fraud Detection

## Description

The Credit Card Fraud Detection project focuses on developing a Machine Learning model capable of identifying fraudulent credit card transactions.

This is an important real-world classification problem because fraudulent transactions generally represent a much smaller proportion of transactions than genuine transactions.

## Key Steps

* Load the transaction dataset.
* Explore the dataset.
* Perform data preprocessing.
* Normalize transaction data where required.
* Analyze the class distribution.
* Handle class imbalance.
* Split the dataset into training and testing sets.
* Train a classification model.
* Predict fraudulent and genuine transactions.
* Evaluate the model using appropriate performance metrics.

## Evaluation Metrics

The project focuses on metrics such as:

* Precision
* Recall
* F1-Score
* Accuracy

For fraud detection, precision, recall, and F1-score are particularly important because accuracy alone may not properly represent performance when classes are highly imbalanced.
